ClaimCourt

An on-chain court for airdrop & token-claim announcements. GenLayer's AI validators fetch the page, judge the claim, and store the verdict on-chain — where anyone can check it.

View the code on GitHub Try it in GenLayer Studio

The problem

Airdrop farmers are spammed daily with fake claim announcements — "$GEN claims are live, connect your wallet!" — most of them phishing pages. Until now there was no neutral, on-chain way to ask: does this page actually say what the post claims it says, and does it show scam red flags?

Four possible verdicts

VERIFIED

The page really makes this claim and shows no serious red flags.

NOT_FOUND

The page loads, but it does not make — or contradicts — the claim.

SUSPICIOUS

Scam red flags: seed-phrase requests, "send to unlock", impersonation, guaranteed-profit promises.

UNREACHABLE

The page could not be read or returned almost no content.

Anyone opens a case with a page URL and the claim being circulated. The contract fetches the page itself; validators independently re-run the judgment and must agree on the verdict — consensus on the decision, not the wording. Page content is treated as untrusted data: the court never follows instructions found on the page it is judging.

Try it yourself (free, ~3 minutes)

  1. Open the GitHub repository and copy contracts/claim_court.py.
  2. In GenLayer Studio, create a contract file, paste the code, and deploy via Run and Debug (Normal / Full Consensus). Studio-network deployment is free — no faucet needed.
  3. Call submit_case with url https://testnet-faucet.genlayer.foundation/ and claim This page lets visitors claim 100 GEN testnet tokens, once per week. Wait for consensus to finalize.
  4. Call get_case with case-1 — the court returns its verdict, a summary, and any red flags, all stored on-chain.
